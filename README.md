# Operating System Simulation

## Project Overview

This project is a console-based Operating System Simulation
developed using C programming.

It demonstrates FCFS (First Come First Serve) CPU Scheduling.

## Features

- Process input
- Arrival Time
- Burst Time
- Completion Time
- Waiting Time
- Turnaround Time
- Average Waiting Time
- Average Turnaround Time
- Gantt Chart

## Technology Used

- C Programming Language
- Cxxdroid
- FCFS Scheduling Algorithm

## How to Run

1. Compile and run the C program.
2. Enter the number of processes.
3. Enter arrival time and burst time.
4. View the process table and Gantt Chart.

## Sample Output

Average Waiting Time: 3.33

Average Turnaround Time: 7.33

## Conclusion

This project demonstrates FCFS CPU Scheduling
and calculates important scheduling parameters.
